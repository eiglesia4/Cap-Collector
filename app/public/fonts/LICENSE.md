# Self-hosted fonts

Latin subsets of the Google Fonts releases, committed so the app never fetches fonts at runtime (CAP-21):

- `space-grotesk-700-latin.woff2` — Space Grotesk 700, © The Space Grotesk Project Authors.
- `dm-sans-latin.woff2` — DM Sans (variable weight), © The DM Sans Project Authors.

Both are licensed under the SIL Open Font License, Version 1.1: https://openfontlicense.org
