# doc/adr

Las decisiones de arquitectura del producto viven en la spec (`doc/spec/decisions/ADR-NNN-slug.md`, del arquitecto;
una decisión tomada no se edita, se sustituye por otra).

Esta carpeta es solo para decisiones **del repositorio** que no quepan allí (tooling, CI, estructura de workspaces).
Formato: `CAP-<n>-<slug>.md` con Contexto · Decisión · Consecuencias · Estado.
